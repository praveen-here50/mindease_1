# MindEase

A student stress manager with meditation, movement, focus tools and calming activities in one app.

The code is in the `mindbloom-buddy-02-main` folder.

## Features

- **Personal setup:** onboarding asks about your field of study and stress level
- **Meditation:** guided meditation sessions
- **Exercise:** yoga, stretching and exercise sessions
- **Mood tracker:** record how you feel over time
- **Pomodoro timer:** focused study sessions with breaks
- **To-do list:** keep track of your tasks
- **Academic calendar:** see the month's events
- **Calming music:** a relaxing playlist
- **Games and stories:** a bubble game and motivational stories
- **Support chat:** a helper with built-in replies
- **Chat rooms:** room-based chat with a nickname, saved in your browser
- **Feedback:** share your thoughts on the app

## Built with

React, TypeScript, Vite, Tailwind CSS, shadcn/ui, Chart.js and Recharts

## Run it locally

You need [Node.js](https://nodejs.org).

```bash
cd mindbloom-buddy-02-main
npm install
npm run dev
```

Then open the local address shown in the terminal.

## Good to know

- This is a student project, not a medical service or a replacement for professional mental health care.
- The support chat uses built-in replies and is not connected to an AI service.
